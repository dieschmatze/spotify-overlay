# Spotify Overlay für Windows

Ein kleines, halbtransparentes Fenster oben rechts zeigt Albumcover, Titel, Interpret und den Fortschritt samt Laufzeit aus der Windows-Mediensteuerung an. Es bleibt im Vordergrund und lässt sich mit der Maus verschieben.

## Starten

Die App ist bereits in `.venv` installiert. Doppelklicke auf `Start Spotify Overlay.bat`, oder starte sie im Terminal mit:

```powershell
.\.venv\Scripts\pythonw.exe .\spotify_overlay.py
```

Spotify muss geöffnet sein und einen Titel an Windows melden. Es ist keine Spotify-Anmeldung oder API-Konfiguration nötig.
